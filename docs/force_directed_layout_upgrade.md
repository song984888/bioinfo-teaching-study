# 🚀 知识图谱力导向布局升级 - 彻底解决重叠问题

## 📋 问题背景

用户连续三次反馈"显示重叠严重"，即使经过两轮激进的网格布局优化（边距 +50%、间距系数 +43%），仍然无法解决标签重叠问题。

### 根本原因分析

**网格布局的固有缺陷：**
1. **固定位置**：节点按网格固定排列，无法根据实际内容自适应调整
2. **空间浪费**：即使某些区域空旷，节点仍按固定网格分布
3. **标签冲突**：标签位置基于固定公式计算，无法避让相邻标签
4. **缺乏交互**：用户无法拖动节点查看被遮挡的内容

---

## ✅ 终极解决方案：力导向布局（Force-Directed Layout）

### 核心原理

使用 D3.js 的物理模拟引擎，通过以下力的平衡实现自动布局：

```
┌─────────────────────────────────────┐
│           力导向模拟系统            │
├─────────────────────────────────────┤
│  🔴 斥力（Charge Force）            │
│     - 强度：-800                    │
│     - 作用：节点互相排斥，避免聚集   │
├─────────────────────────────────────┤
│  🔵 引力（Center Force）            │
│     - 中心点：画布中央              │
│     - 作用：防止节点飞出画布         │
├─────────────────────────────────────┤
│  🟢 碰撞检测（Collide Force）       │
│     - 半径：节点半径 + 60px         │
│     - 作用：强制保持安全距离         │
├─────────────────────────────────────┤
│  🟡 弹簧力（Link Force）            │
│     - 长度：150px                   │
│     - 作用：关联节点保持适当距离     │
└─────────────────────────────────────┘
```

## 🎯 技术实现

### 1. 力导向模拟器配置

```javascript
const simulation = d3.forceSimulation(nodes)
    .force('link', d3.forceLink(links).id(d => d.id).distance(150))
    .force('charge', d3.forceManyBody().strength(-800))
    .force('center', d3.forceCenter(width / 2, height / 2))
    .force('collide', d3.forceCollide().radius(d => d.size + 60).iterations(3));
```

#### 参数详解

| 力类型 | 参数 | 值 | 作用 |
|--------|------|-----|------|
| **Link** | distance | 150px | 关联节点间的理想距离 |
| **Charge** | strength | -800 | 节点间斥力强度（负值越大斥力越强） |
| **Center** | x, y | width/2, height/2 | 画布中心引力点 |
| **Collide** | radius | node.size + 60px | 碰撞检测的安全半径 |
| **Collide** | iterations | 3 | 迭代次数（越多越精确） |

### 2. 动态更新机制

```javascript
simulation.on('tick', () => {
    // 每帧更新连线位置
    links.attr("x1", d => d.source.x)
         .attr("y1", d => d.source.y)
         .attr("x2", d => d.target.x)
         .attr("y2", d => d.target.y);
    
    // 每帧更新节点位置
    nodes.attr("cx", d => d.x)
         .attr("cy", d => d.y);
    
    // 每帧更新标签位置（节点上方）
    labels.attr("x", d => d.x)
          .attr("y", d => d.y - d.size - 15);
});
```

### 3. 拖拽交互功能

```javascript
.call(d3.drag()
    .on("start", dragstarted)
    .on("drag", dragged)
    .on("end", dragended));

function dragstarted(event, d) {
    if (!event.active) simulation.alphaTarget(0.3).restart();
    d.fx = d.x; // 固定节点
    d.fy = d.y;
}

function dragged(event, d) {
    d.fx = event.x; // 跟随鼠标移动
    d.fy = event.y;
}

function dragended(event, d) {
    if (!event.active) simulation.alphaTarget(0);
    d.fx = null; // 释放节点
    d.fy = null;
}
```

## 🎓 技术原理深入

### 力导向算法历史

- **1991 年**：Fruchterman & Reingold 提出经典 FR 算法
- **1993 年**：Kamada & Kawai 提出 KK 算法
- **2000 年代**：力导向布局成为图可视化标准方法
- **2010 年代**：D3.js 将其带入前端开发

### 物理模拟原理

```
总受力 = 斥力 + 引力 + 弹簧力 + 碰撞力

每个节点的加速度：a = F / m（质量默认为 1）
速度更新：v = v × 阻尼 + a × dt
位置更新：p = p + v × dt
```

### 收敛条件

- **Alpha 值**：模拟强度从 1.0 衰减到 0.001
- **能量最小化**：系统总能量趋近于局部最优
- **视觉稳定**：节点位置变化小于 0.1px

## 🔧 故障排查

### 问题 1：节点全部聚集在中心

**原因**：斥力不够强  
**解决**：降低 `charge.strength`（如从 -800 改为 -1500）

### 问题 2：节点飞出画布

**原因**：斥力太强或引力太弱  
**解决**：
1. 提高 `charge.strength`（如从 -1500 改为 -500）
2. 增强中心引力（添加 `forceCenter`）

### 问题 3：标签仍然重叠

**原因**：标签间距太小  
**解决**：增加标签偏移量（从 `-d.size - 15` 改为 `-d.size - 25`）

### 问题 4：拖拽时节点抖动

**原因**：Alpha 值过高  
**解决**：在 `dragstarted` 中设置更低的 `alphaTarget`（如 0.1）
