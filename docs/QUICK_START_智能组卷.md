# 智能组卷功能 - 快速使用指南

## 🚀 快速开始

### 前提条件
1. 系统中已有已审核的题目（通过题库审核功能）
2. 教师账号可以正常登录
3. Flask 应用正在运行

### 使用步骤

#### 步骤 1: 登录系统
访问：`http://localhost:1234/login`
- 输入教师账号和密码
- 点击登录

#### 步骤 2: 进入智能组卷
在教师控制台页面，找到并点击"📋 智能组卷"卡片

#### 步骤 3: 填写试卷信息

**基本信息**:
```
试卷名称：2024 年春季学期 Python 期末考试
课程名称：Python 程序设计
考试时长：90（分钟）
```

**题目配置**:
1. 点击"+ 添加题目类型要求"
2. 选择题目类型（如：程序设计题）
3. 设置数量：
   - A 卷数量：3
   - B 卷数量：3
   - 每题分值：15
   - 难度分布：混合难度

4. 再次点击"+ 添加题目类型要求"
5. 选择题目类型（如：理论题）
6. 设置数量：
   - A 卷数量：5
   - B 卷数量：5
   - 每题分值：4
   - 难度分布：中等

**实时查看总分**:
```
统计信息:
A 卷总分：65 分
B 卷总分：65 分
总题目数：16 题
```

#### 步骤 4: 生成试卷
点击"生成试卷"按钮，等待系统处理...

#### 步骤 5: 预览试卷
系统自动跳转到预览页面，可以：
- 切换查看 A 卷或 B 卷
- 查看每道题的详细信息
- 查看参考答案和评分标准
- 下载 PDF（功能开发中）
- 打印试卷

## 💡 使用技巧

### 1. 合理分配题型
建议编程题和理论题搭配使用：
- 编程题：考查实践能力（10-20 分/题）
- 理论题：考查理论知识（2-5 分/题）

### 2. 难度梯度设置
- 基础考试：简单 60% + 中等 30% + 困难 10%
- 选拔考试：简单 20% + 中等 50% + 困难 30%
- 平时测验：以简单和中等为主

### 3. 题目数量建议
根据考试时长合理安排：
- 90 分钟：8-12 题
- 120 分钟：15-20 题
- 编程题较多时，适当减少总题量

### 4. A/B 卷策略
- 期中/期末考试：A/B 卷题目数量相同
- 补考/重考：B 卷题目可以略少于 A 卷
- 练习测试：可以只使用 A 卷

## ⚠️ 常见问题

### Q1: 提示"题目数量不足"
**原因**: 题库中没有足够符合条件的题目

**解决方案**:
1. 减少题目数量要求
2. 降低难度要求（选择"混合难度"）
3. 先到"题库审核"中添加更多题目

### Q2: 生成的试卷总分不对
**检查**:
1. 确认每种题型的"每题分值"设置正确
2. 查看实时统计中的总分显示
3. 如有问题，刷新页面重新配置

### Q3: 无法进入组卷页面
**原因**: 权限不足或未登录

**解决方案**:
1. 确认已使用教师账号登录
2. 检查 Session 是否过期
3. 重新登录后再试

### Q4: B 卷题目数量少于 A 卷
**原因**: 题库题目总数不足

**解决方案**:
1. 减少 A/B 卷的题目数量
2. 增加题库中的题目数量
3. 系统会自动从剩余题目中选择，不会重复

## 🔧 技术说明

### 数据存储
- 试卷信息保存在 `exam_papers` 表
- 题目数据以 JSON 格式存储
- 包含完整的题目、答案、评分标准

### 组卷算法
1. 从已审核题目中筛选
2. 按题型、难度分类
3. 随机抽取 A 卷题目
4. 从剩余题目中抽取 B 卷
5. 确保 A/B 卷不重复

### 安全性
- 只有教师角色可以访问
- 所有操作都需要登录验证
- 防止 SQL 注入和 XSS 攻击
