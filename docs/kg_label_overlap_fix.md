# 知识图谱标签重叠问题修复报告

## 📋 问题描述

用户反馈：**概念文本与下一行的频次文字重叠了**

### 问题分析

**原布局间距不足**：
- 概念名称在节点上方：`y = concept.y - 25 - 8`（距离节点边缘 8px）
- 频次标签在节点下方：`y = concept.y + 25 + 18`（距离节点边缘 18px）
- 评分标签在频次下方：`y = concept.y + 25 + 34`（距离频次标签 16px）

**当节点较大时（最大 50px）**：
- 节点半径：50px
- 概念名称字体：16px（高度约 19px）
- 频次标签字体：13px（高度约 16px）
- 评分标签字体：12px（高度约 14px）

**计算示例（最大节点 50px）**：
```
节点中心 y = 200px
节点顶部 y = 200 - 50 = 150px
节点底部 y = 200 + 50 = 250px

概念名称位置 = 200 - 50 - 8 = 142px（基线）
概念名称实际占用空间 ≈ 132px - 151px（16px 字体 + 上下留白）

频次标签位置 = 200 + 50 + 18 = 268px（基线）
频次标签实际占用空间 ≈ 260px - 276px（13px 字体 + 上下留白）

⚠️ 问题：当节点更大或标签更长时，容易重叠！
```

## ✅ 解决方案

### 增加标签垂直间距

#### 1. 概念名称标签（节点上方）

**修改前**：
```javascript
.attr("y", concept.y - (concept.size || 25) - 8) // 间距 8px
```

**修改后**：
```javascript
.attr("y", concept.y - radius - 12) // 间距增加到 12px
```

**改进**：
- ✅ 间距从 8px 增加到 12px（+50%）
- ✅ 为大字节点留出更多空间
- ✅ 避免与节点圆圈接触

#### 2. 频次标签（节点下方）

**修改前**：
```javascript
.attr("y", concept.y + (concept.size || 25) + 18) // 间距 18px
```

**修改后**：
```javascript
.attr("y", concept.y + radius + 24) // 间距增加到 24px
```

**改进**：
- ✅ 间距从 18px 增加到 24px（+33%）
- ✅ 确保与大节点不重叠
- ✅ 视觉上更舒适

#### 3. 评分标签（频次下方）

**修改前**：
```javascript
.attr("y", concept.y + (concept.size || 25) + 34) // 与频次间隔 16px
```

**修改后**：
```javascript
.attr("y", concept.y + radius + 42) // 与频次间隔 18px
```

**改进**：
- ✅ 与频次标签的间距从 16px 增加到 18px
- ✅ 避免两个底部标签重叠
- ✅ 层次更清晰

## 🎯 技术要点

### 1. 统一使用 radius 变量

**修改前**：
```javascript
// 多次重复计算
concept.y - (concept.size || 25) - 8
concept.y + (concept.size || 25) + 18
concept.y + (concept.size || 25) + 34
```

**修改后**：
```javascript
const radius = concept.size || 25; // 统一变量

concept.y - radius - 12
concept.y + radius + 24
concept.y + radius + 42
```

**优势**：
- ✅ 代码更简洁
- ✅ 避免重复计算
- ✅ 易于维护和调整

### 2. 阶梯式间距设计

```
概念名称 ← 12px → 节点 ← 24px → 频次 ← 18px → 评分
     ↑                    ↑                   ↑
   上方间距            下方间距           底部间距
```

**设计原则**：
- 上方间距较小（12px）：概念名称较短，不易遮挡
- 下方间距较大（24px）：给频次标签留出空间
- 底部间距适中（18px）：评分标签可选，层次清晰

### 3. 响应式间距适配

间距根据节点大小动态调整：
```javascript
间距 = 基础间距 + 节点半径补偿
```

**效果**：
- 大节点 → 自动增加间距
- 小节点 → 保持紧凑但不拥挤
- 所有节点 → 标签不重叠
