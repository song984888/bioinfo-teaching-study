# 题目详情页理论题支持修复说明

## 问题描述

**用户报告**：刚刚生成的题目，点击待审核的题目，提示不存在

**问题根源**：`question_detail` 函数只查询了 `questions` 表，但理论题目存储在 `theory_questions` 表中，导致找不到题目。

## 修复方案

**文件**：`app.py`  
**位置**：第 3455-3509 行  
**函数**：`question_detail(question_id)`

```python
try:
    # 获取题目信息 - 同时支持 questions 表和 theory_questions 表
    cursor.execute("SELECT * FROM questions WHERE id = %s", (question_id,))
    question = cursor.fetchone()
    
    if not question:
        # 尝试查询 theory_questions 表（理论题）
        cursor.execute("SELECT * FROM theory_questions WHERE id = %s", (question_id,))
        question = cursor.fetchone()
        
        if not question:
            flash('题目不存在', 'danger')

        question['is_theory'] = True

    # 解析提示信息
    hints = json.loads(question.get('hints')) if question.get('hints') else []
    
    # 获取使用统计 - 理论题可能没有考试/练习记录
    usage_stats = {
        'exam_count': 0,
        'exercise_count': 0,

    # 只有非理论题才查询考试和练习统计
    if not question.get('is_theory'):
        # 考试使用次数
        cursor.execute("SELECT COUNT(*) AS count FROM exams WHERE question_id = %s", (question_id,))
        exam_count = cursor.fetchone()['count']
        usage_stats['exam_count'] = exam_count
        
        # 练习使用次数
        cursor.execute("SELECT COUNT(*) AS count FROM exercises WHERE question_id = %s", (question_id,))
        exercise_count = cursor.fetchone()['count']
        usage_stats['exercise_count'] = exercise_count
        
        # 平均得分
        cursor.execute("""
            SELECT AVG(score) AS avg_score
            FROM (
                SELECT ai_score AS score FROM exams WHERE question_id = %s
                UNION ALL
                SELECT ai_score AS score FROM exercises WHERE question_id = %s
            ) AS scores
        """, (question_id, question_id))
        
        avg_score = cursor.fetchone()['avg_score']
        usage_stats['avg_score'] = avg_score or 0
```

## 技术细节

### 双表字段差异

| 字段名 | questions 表 | theory_questions 表 | 说明 |
|--------|--------------|---------------------|------|
| `hints` | ✅ 有 | ❌ 无 | 编程题的提示信息（JSON 格式） |
| `language` | ✅ 有 | ❌ 无 | 编程语言（Python/Java 等） |
| `grading_criteria` | ❌ 无 | ✅ 有 | 理论题评分标准 |
| `score` | ❌ 无 | ✅ 有 | 理论题分值 |

### 查询策略

采用**优先查询 + 降级查询**的策略：

1. **第一步**：先查询 `questions` 表
2. **第二步**：如果没找到，再查询 `theory_questions` 表
3. **第三步**：如果两个表都没找到，返回"题目不存在"
4. **第四步**：如果是理论题，标记 `is_theory = True` 并补充缺失字段

### 兼容性处理

- **提示信息**：理论题没有 `hints` 字段，设置为 `None`
- **使用统计**：理论题暂时没有考试/练习记录，跳过查询
- **前端显示**：通过 `is_theory` 标记区分显示内容
