# 基于AI大模型的生物信息学课程教学一体化平台

中文生物信息学在线教学平台（原名《生物信息学课程》教&学系统），支持编程练习、考试测评、知识库管理、学习笔记和智能学习建议等功能。

## 主要功能

### 1. 题库管理系统
- **编程题库**：10,612+ 道编程题目，涵盖 Perl、Python、C 等语言
- **难度分级**：初级（4,810题）、中级（3,434题）、高级（2,368题）
- **主题分类**：正则表达式、文件测试、列表变量、数组变量等 Chapter 主题
- **理论题库**：概念理解和理论知识题目

### 2. 学生端功能

#### 抽题练习
- **智能选题流程**：题型 → 主题 → 语言 → 难度
- **实时题目统计**：每个选项显示可用题目数量
- **智能过滤**：自动隐藏无题目的选项，避免空选
- **代码编辑器**：支持语法高亮、自动补全
- **即时反馈**：自动评测和AI评分

#### 模拟考试
- **自定义考试**：选择主题、难度和题目数量
- **限时测试**：支持倒计时和自动提交
- **成绩报告**：详细的答题统计和分析

#### 知识库学习
- **文献管理**：上传和浏览生物信息学文献
- **核心概念**：自动提取和关联文献中的核心概念
- **概念学习中心**：聚合所有公开知识库的概念
- **浏览记录**：跟踪学生的知识库浏览行为

#### 生信工具学习
- **九大分类**：Bioinformatics Programming（生物信息学程序设计）、Gene Information Search、Gene Expression、DNA Alignment、Genetic Variations、Protein Informations、Protein Expression、Protein Interactions、Protein Structure and Function Prediction
- **分类标识**：每个分类配有原创内联 SVG 小 Logo（绑定稳定 slug，管理员改名不丢图标）
- **工具目录**：99 个经来源核验的外部工具（含管理员自建分类），带详情页、来源链接与核验日期，支持搜索/排序
- **学习追踪**：学生点击"访问工具"时经平台跳转路由记录工具与主题（教师/管理员点击不记录）
- **统计分析**：总点击次数、近30天点击、使用工具数、主题偏好、常用工具排名
- **管理员维护**：`/admin/bioinformatics-tools` 可新建/编辑分类与工具的名称、简介、链接、排序与发布状态；启动播种幂等（仅缺失时插入），管理员编辑不被重启覆盖

#### 学习笔记
- **传统笔记**：关联知识库、概念和文档的学习笔记
- **思维链**：绑定知识库和核心概念的结构化思维过程
- **合并统计**：学生首页统一显示传统笔记和思维链总数

#### 学习建议
- **数据驱动**：基于练习、考试、知识库、工具和笔记的综合分析
- **AI生成**：使用 DeepSeek 或 Ollama 模型生成个性化建议
- **历史查看**：顶栏「🗂️ 历史学习建议查看」入口，多条记录列表展示，点击展开即按**原始建议页面完整回放**（含主题分布条形图和难度饼图等全部图表，两处共用同一报告模板，样式完全一致）
- **可靠落库**：生成时将练习/考试/知识库/工具/笔记指标以 JSON 快照随建议一并保存；三张指标表与建议各自独立写入，任一指标缺失不阻断历史保存
- **多维度评估**：
  - 编程练习成绩和主题掌握度
  - 考试成绩和错误模式
  - 知识库浏览兴趣和文献阅读
  - 生信工具使用频率和主题偏好
  - 学习笔记数量和知识整理习惯

#### 学习进度统计
- 概念学习数量
- 抽题练习次数
- 文献检索记录
- 学习笔记总数（传统笔记 + 思维链）
- 生信工具使用数（使用过的不同工具数量）

#### ☕ 生物信息学小游戏（Take a Break）
- **入口**：学生、教师、管理员控制台均有「Take a break」卡片 → `/games/coffee-break` 游戏大厅（登录后即可访问）
- **六款小游戏**，将生信概念做成轻松玩法：
  - **ALIGN-O-MATIC**：把读段滑到参考序列上，找出最佳比对（无计时）
  - **CODON RUSH**：倒计时内把密码子对应到正确氨基酸
  - **GC GUESSER**：估算序列的 GC 含量，练"基因组学家手感"
  - **ORF HUNTER**：在正链上找出最长开放阅读框
  - **MOTIF HUNT**：像限制性内切酶一样扫描，点击所有酶切位点
  - **MINI ASSEMBLER**：动手体验 overlap-layout-consensus 组装思路
- **设计约定**：大厅内嵌各游戏页面，游戏页仅显示自身内容与公共页脚（不重复顶栏导航）；游戏内提供"返回继续学习"按钮回控制台
- **纯前端实现**：游戏为静态 HTML/JS，经白名单路由 `/games/<filename>`（仅放行 7 个页面 + 1 个 align-o-matic.js 脚本）登录后提供，无服务器端状态、不产生学习数据

### 3. 教师端功能
- **题目审核**：审核学生提交的编程题目
- **知识库管理**：创建和编辑知识库、上传文献、标注概念
- **学生管理**：查看学生学习详情、练习记录、考试成绩
- **学习建议查看**：查看学生的AI生成学习建议（包含笔记统计）
- **生信工具管理**：添加、编辑和分类生物信息学工具

### 4. 管理员功能
- **用户管理**：管理学生和教师账号
- **题库导入**：批量导入编程题目（支持 SQL 格式）
- **系统配置**：配置考试、练习、知识库等模块
- **数据统计**：全局学习数据和系统使用情况

## 技术栈

- **后端**：Python Flask
- **数据库**：MySQL / MariaDB
- **前端**：HTML5, CSS3, JavaScript (Vanilla)
- **AI集成**：DeepSeek API / Ollama (本地模型)
- **代码编辑器**：Ace Editor

## 数据库表结构

### 核心表
- `users` - 用户账号（学生、教师、管理员）
- `questions` - 题库（编程题和理论题）
- `exercises` - 学生练习记录
- `exams` - 考试记录
- `knowledge_bases` - 知识库
- `knowledge_documents` - 知识库文献
- `knowledge_concepts` - 核心概念
- `student_notes` - 学生学习笔记
- `thought_chains` - 学生思维链
- `bioinformatics_tool_categories` - 生信工具分类
- `bioinformatics_tools` - 生信工具库
- `student_tool_activity` - 学生工具点击记录
- `study_suggestions` - 学习建议记录（含 `metrics_snapshot` 指标快照）
- `exercise_metrics` / `exam_metrics` - 学生练习/考试聚合指标

### 浏览记录表
- `concept_view_logs` - 概念浏览记录
- `kb_view_logs` - 知识库浏览记录
- `document_view_logs` - 文档查看记录

## 配置要求

- Python 3.9+
- MySQL 5.7+ / MariaDB 10.3+
- Flask 及相关依赖（见 `requirements.txt`）
- （可选）DeepSeek API Key 或 Ollama 本地部署
