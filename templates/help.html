🔐 通用操作

  • 登录：使用学号/工号 + 密码登录，角色由账号决定（student / teacher / admin）。
  • 首页：控制台入口，集中所有功能卡片。
  • 个人账号：修改密码、查看账户信息（控制台右上角或导航「账号管理」）。
  • 文献检索：检索生物信息学文献并做单篇深入研读（见下方说明）。

🎓 学生功能

  • 概念学习：汇聚所有公开知识库的核心概念，支持搜索和类型筛选，点击可查看定义、来源文档和相关概念。
  • 抽题学习：选择题型（编程题 / 理论题），理论题可按知识库→概念→难度进行选择，支持 AI 自动评阅。
  • 学习笔记：以概念为单位记录学习心得，支持思路链条（延续想法）和快速灵感捕捉。概念学习、抽题练习、文献检索中均可关联概念保存笔记。
  • 知识库浏览：查看公开知识库文档、交互式知识图谱（D3.js 力导向布局），点击概念节点可检索相关文献。
  • 文献检索：检索生物信息学顶级期刊文献，AI 自动提取创新点与应用，支持深入研读和导出。
  • 学习反馈：系统根据练习和知识库学习数据，由 AI 生成个性化学习建议报告。
  • 我的学习进度：首页下方实时显示概念学习、抽题练习、文献检索、学习笔记四项统计数据。

🧑‍🏫 教师 / 管理员功能

  • AI 出题（编程）：选择主题 / 难度 / 语言，调用 DeepSeek 或 Ollama 生成编程题，后台任务异步执行。
  • 理论题生成：基于知识库或 PDF，按题型（名词解释 / 填空 / 判断 / 单选 / 多选 / 简答 / 论述 / 案例分析 / 综合）生成理论题。
  • 题目审核：在「待审核」中通过 / 驳回 / 删除题目；通过后进入题库。
  • 题库：浏览已通过题目，支持筛选与分页。
  • 智能组卷：按题型、数量、分值、难度分布生成 A/B 双卷，可预览并导出 PDF。
  • 考试记录：查看学生考试详情，教师可手动复核 / 修正分数。
  • 知识库：上传 PDF / TXT / Word 文档，自动抽取概念与关系，生成知识图谱。
  • 后台任务：查看 AI 生成任务的进度、日志与结果，失败时可重启。

🧬 文献检索（Bioinformatics 文献智能检索）

  • 检索：多选目标期刊 + 关键词 + 年份范围，点击「检索文献」。
  • 创新点提取：每篇卡片「提取创新点与应用」自动抽取核心创新点与成果应用；「批量提取」可一次性分析全部结果。
  • 深入研读：点击「深入研读」打开弹窗，将单篇文献结构化为 关键词 / 方法&工具 / 结果 / 讨论&未来 / 待解决问题 / 图表；点击关键词可重新检索。
  • 导出：将结果导出为 CSV（含 BOM，Excel 可直接打开）。
  • 期刊维护：教师 / 管理员点击期刊选择框旁的「⚙ 管理」可添加、重命名、删除目标期刊。

❓ 常见问题

  • 代码运行支持 Python / Java / C / Perl，运行在临时目录，超时 30 秒。
  • AI 功能依赖 DeepSeek API 或本地 Ollama；若 API 不可用，相关功能会回退或报错提示。
  • 文献数据来自 Europe PMC 公开接口，全文 / 图表依赖其 OA 子集可用性。
